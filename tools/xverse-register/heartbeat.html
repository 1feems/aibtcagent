Xverse Trigger for AIBTC Heartbeat

Registration is done. This helper generates a fresh heartbeat timestamp, triggers the Xverse BTC signing prompt, and then shows a one-command fallback submit for the signed check-in.

Use the same Chrome profile where the Xverse extension is installed.

Heartbeat Payload

Heartbeats are limited to one check-in per 5 minutes. If Xverse shows a send, PSBT, fee, inputs, or outputs, cancel it.
